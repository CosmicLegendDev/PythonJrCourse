# Variables

## What is a Variable?

A variable is a named storage location in a program that holds a value. Variables allow you to store, retrieve, and manipulate data throughout your code.

## How to Declare Variables

In python we declare variabels by simply assigning a value to a name using the equals sign (`=`).

```python
# Declaring variables
age = 25 #here age is called as variable.
name = "Alice"
height = 5.7
is_student = True
```

## When to use variables?

Variables are used whenever you need to store data that may change or be reused throughout your program.
