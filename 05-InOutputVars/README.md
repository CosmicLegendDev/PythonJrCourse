# Input and output variables in python.

In python, we can use variables to store values and perform operations on them. We can also use input() function to get user input and print() function to display output.

# Example of input and output variables in python.

name = input("Enter your name: ")
age = input("Enter your age: ")

print("Hello, " + name + "! You are " + age + " years old.")

### Note: Everything we read from terminal using input() function is in the datatype of String.
